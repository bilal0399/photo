# لوحة الإدارة — ديوان الفرقة 42

موقع ويب (HTML و CSS و JavaScript فقط، بدون أي أداة بناء) لإدارة الأرشيف. يعمل على قاعدة البيانات نفسها التي يستخدمها التطبيق، و**يدخله حساب المدير فقط**.

## الصفحات

| الصفحة | ماذا تفعل |
|---|---|
| نظرة عامة | أرقام سريعة (الإجمالي، هذا الشهر، بدون مرفق، قيد المراجعة) ورسوم للطلبات حسب الشهر والحالة والجهة |
| الطلبات | بحث لا يتأثر بالهمزات والتاء المربوطة، وفلاتر، وعرض الصورة، وتعديل وحذف، وتصدير Excel للنتائج |
| إدخال سريع | إدخال طلبات متتالية: القوائم تبدأ فارغة للبحث، وبعد الحفظ يبقى التاريخ والنوع والجهة ويتقدّم الرقم. `Ctrl+Enter` للحفظ والتالي، والصق الصورة مباشرة بـ `Ctrl+V` |
| الصور | **إرفاق جماعي حسب اسم الملف** (الصورة `7.jpg` تُرفق بالطلب رقم 7)، و**معالجة الصور القديمة** |
| المستخدمون | إنشاء الحسابات وتعديلها (الاسم، البريد، كلمة المرور، الصلاحية) وحذفها |
| القوائم | أنواع الكتب والجهات والحالات: إضافة وتعديل (مع تحديث الطلبات القديمة) وحذف وترتيب |
| النسخ الاحتياطي | نسخة كاملة بصيغة نسخة التطبيق نفسها: `records.xlsx` مع كل الصور في ملف ZIP |

كل صورة تُضاف من اللوحة تُقتص وتُحسَّن بالخوارزمية نفسها التي يستخدمها التطبيق (`js/scanner-core.js` نسخة من `lib/core/scanner/document_scanner.dart`).

## التفعيل (مرة واحدة)

تحتاج [Supabase CLI](https://supabase.com/docs/guides/cli) مربوطاً بالمشروع (`supabase link`)، ثم من مجلد المشروع:

1. **الصلاحيات**: تمنح حساب المدير صلاحية إدارة القوائم والطلبات والملفات والملفات الشخصية. لا تغيّر صلاحيات المستخدم العادي.
   ```bash
   supabase db push
   ```
   أو الصق محتوى `supabase/migrations/20260927000000_admin_dashboard.sql` في SQL Editor.

2. **دالة إدارة الحسابات**: إنشاء الحسابات وحذفها يحتاج المفتاح السري، وهذا المفتاح يبقى على الخادم داخل الدالة ولا يوضع في الموقع أو التطبيق.
   ```bash
   supabase functions deploy admin-users
   ```

3. **إيقاف التسجيل العام** (مستحسن جداً): من Supabase ← Authentication ← Sign In / Providers ← عطّل **Allow new users to sign up**.
   بعد ذلك لا يُنشأ أي حساب إلا عن طريق المدير. التطبيق يستخدم الدالة نفسها عند إضافة مستخدم.

## التشغيل

الأسهل: افتح `index.html` في المتصفح. هذا يعمل، لكن المتصفح يمنع المعالجة في الخلفية للملفات المحلية، فتكون معالجة الصور الكثيرة أبطأ.

الأفضل: شغّله من خادم بسيط:

```bash
cd dashboard
python -m http.server 8080
# ثم افتح http://localhost:8080
```

أو ارفع مجلد `dashboard` كما هو على أي استضافة ملفات ثابتة (Netlify أو GitHub Pages أو خادم داخلي).
يحتاج اتصالاً بالإنترنت لتحميل المكتبات (supabase-js و JSZip و SheetJS) من cdn.jsdelivr.net.
